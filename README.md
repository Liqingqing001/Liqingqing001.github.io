# 李晴 · 个人作品集

纯静态个人主页，展示六个公开项目，以及单独注明来源的 Playwright Fork。

## 文件

- `index.html`：个人介绍、项目说明与链接。
- `style.css`：桌面及移动端布局。
- `app.js`：项目分类筛选。
- `favicon.svg`：站点图标。

无需安装依赖或构建。GitHub Pages 使用 `main` 分支根目录发布。

页面每次打开会通过 GitHub 公共 API 获取当前公开仓库，并读取 README 的首个介绍段落：更新现有项目说明、新增公开项目卡片，并显示仓库推送日期。个人简介仍由本人维护。私有仓库不会被访问，Fork 不混入原创项目列表，网站仓库自身不作为作品计数。

`index.html` 中的六个项目是无需联网也可展示的快照。网络失败或公共 API 限流时保留快照并显示提示；首次使用的访客能看到最新 README，保持打开的旧页面需刷新。新项目方向按仓库名、描述和 topics 推断，可通过编辑静态卡片进一步定制。代码更新若未修改 README 或仓库描述，文字介绍不会自动推断新功能。

页面中的项目缩略图为概念界面示意。实际功能及演示边界以各项目说明为准。
